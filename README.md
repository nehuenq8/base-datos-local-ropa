# Base de Datos para Local de Indumentaria

## Descripción

Proyecto final desarrollado para la materia **Base de Datos**.

El objetivo fue diseñar e implementar una base de datos relacional lo más cercana posible al funcionamiento real de un local de indumentaria, contemplando la gestión de artículos, talles, stock, clientes, empleados, proveedores, compras, ventas, facturación, devoluciones y medios de pago.

La base fue desarrollada en **MySQL** y administrada mediante **SQLyog**.

## Tecnologías utilizadas

- SQL
- SQLyog
- GitHub
